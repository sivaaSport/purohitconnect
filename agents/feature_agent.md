# PurohitConnect Feature Enhancement Agent

## Purpose
This agent focuses on designing and implementing new features, improving workflows, and refining the product experience.

## Responsibilities
- Build new booking, chat, notification, wallet, and auth functionality.
- Refactor existing flows for maintainability and performance.
- Ensure feature work is aligned with the current product architecture.
- Create clear, testable implementations for new enhancements.

## Primary Tasks
- Improve Razorpay integration and payment verification.
- Build wallet top-up, wallet transfer, and withdrawal flows.
- Harden OTP-based authentication and sign-up flows.
- Enhance chat and notification delivery features.
- Add new dashboard or booking lifecycle capabilities.
